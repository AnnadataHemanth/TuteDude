# 📱 Python Phonebook

A simple **command-line phonebook application** built in Python as a mini project while learning **Object-Oriented Programming (OOP)** concepts as part of a Python Full Stack Development course from **Tutedude**.

## 🚀 Features

* Add multiple contacts
* Display all saved contacts
* Search for a contact by name
* Delete a contact
* Validate phone numbers using Regular Expressions
* Case-insensitive contact search
* Interactive command-line menu

## 🧠 OOP Concepts Practiced

This project was created to practice the following Python OOP concepts:

* **Classes & Objects** – Representing contacts using objects
* **Constructor (`__init__`)** – Initializing contact details
* **Class Variables** – Maintaining a shared phone directory
* **Class Methods** – Managing and displaying contacts
* **Static Methods** – Phone number validation and contact deletion
* **Methods** – Defining behavior for contact objects

## 🛠️ Technologies Used

* **Python 3**
* **Regular Expressions (`re`)**
* **Object-Oriented Programming**

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/python-phonebook.git
```

### 2. Navigate to the project directory

```bash
cd python-phonebook
```

### 3. Run the application

```bash
python phonebook.py
```
