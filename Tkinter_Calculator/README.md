# Tkinter Calculator

This is a simple calculator project created using Python and Tkinter as part of my course at Tutedude. This project provides a basic graphical interface for performing arithmetic operations such as addition, subtraction, multiplication, and division.

**Features**
- Simple graphical user interface
- Number buttons from 0–9
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Clear (C) button
- Equals (=) button
- Displays numbers and results in an entry box

**Technologies Used**
- Python
- Tkinter

**How It Works**

The calculator uses Tkinter buttons to take user input.

1. The user enters the first number.
2. An arithmetic operator is selected.
3. The first number is stored and the entry box is cleared.
4. The user enters the second number.
5. Pressing the = button performs the selected operation.
6. The result is displayed in the entry box.

**How to Run**
1. Clone this repository:
git clone 
2. Navigate to the project folder:
cd tkinter-calculator
3. Run the Python file:
python calculator.py

The calculator window will open.
